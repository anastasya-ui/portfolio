# Anastasia Konyuhova — Portfolio

Personal portfolio site. Single self-contained page: `index.html`
(HTML/CSS/JS, embedded photo and animated project cover, dark/light
theme + EN/RU toggle, fully responsive).

## Publish with GitHub Pages
1. Create a new repository (e.g. `portfolio`).
2. Upload `index.html` (and this README, `.nojekyll`) to the repo root.
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/root` → Save.
4. In ~1 minute the site is live at `https://<username>.github.io/<repo>/`.

A custom domain can be added later in Settings → Pages → Custom domain.
